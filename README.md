# DSA Practice Tracker

A responsive browser app for organizing coding practice. It starts empty, so the tracker reflects problems you have actually worked on.

## Run it

Open index.html in a recent browser. No installation, account, server, or internet connection is required. The app uses system fonts if online fonts are unavailable.

## Features

- Add problems with a topic, difficulty, platform, link, status, attempts, practice date, and notes.
- Edit, delete, reopen, and mark problems solved.
- Search and filter by status or difficulty; sort by date, title, or difficulty.
- See solved progress, difficulty counts, a streak, recent activity, and most-used topics.
- Export a JSON backup or import a previous backup.
- Store records in this browser's local storage on this device.

## Privacy

Problems are saved in this browser and are not uploaded to a server. Clearing browser data can remove them, so export a backup if you want a copy.

## Tech

HTML, CSS, and vanilla JavaScript. There are no runtime dependencies.
